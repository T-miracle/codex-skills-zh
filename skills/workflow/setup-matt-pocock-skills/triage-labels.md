# 分流标签（Triage Labels）

这些技能使用五种规范的分流角色（triage roles）。本文件把这些角色映射到此仓库问题跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本跟踪器中的标签 | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 需要维护者评估此问题                     |
| `needs-info`               | `needs-info`         | 正在等待报告者补充信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 说明已完整，可交给 AFK agent             |
| `ready-for-human`          | `ready-for-human`    | 需要由人类实现                           |
| `wontfix`                  | `wontfix`            | 不会采取行动                             |

当技能提及某个角色时（例如“应用 AFK-ready triage label”），使用此表中对应的标签字符串。

请编辑右侧列，使其匹配你实际使用的词汇。
